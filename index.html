How to play?

  • Name must include exactly 3 digits (e.g. Eliya123) to find friends online
  • Solo: joystick / WASD · books with Space or 📖
  • Two players: P1 = WASD + Space · P2 = arrows + Enter (or E)
  • Mobile: 📖 next to each stick, or tap half the screen (left=P1, right=P2)
  • In two-player mode books are available from level 1
  • Find the key 🔑 and escape through the door 🚪
  • From world 1 level 5: books 📖 lock onto zombies and freeze them 5s
  • Co-op: both must reach the door. If caught you freeze — friend revives you
  • Versus: 7 special stages. First to the door wins. Grab 🍌/🧴/🪑
  • Coins: +3 per level, +10 boss, +2 if you already cleared it — never lost on death
  • Continue: progress saves automatically
  • Worlds: 10 levels + boss. 3 lives — restart current world
